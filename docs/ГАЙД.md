# The Shooting Star (Demo) 1.5.2 — как поиграть

Порт мода в Horizon: заклинания, предмет «Stellar Remote», эффекты, катсцены и меню
переписаны как **native-мод** (Rust, его собирает Horizon Launcher), а блоки,
предмет, звуки, шейдеры и текстуры оригинала лежат в **контент-моде**, который
установщик собирает из оригинального jar на твоём компьютере.

## Установка и обновление

Одна команда в PowerShell (Windows):

```powershell
irm https://raw.githubusercontent.com/Oxyg1/shooting-star-horizon/main/install/install.ps1 | iex
```

Linux и macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/Oxyg1/shooting-star-horizon/main/install/install.sh | bash
```

Установщик скачивает оригинал с CurseForge (≈145 МБ, один раз), собирает
контент-мод в `%APPDATA%\horizon\horizon-mods\shooting_star_demo`, ставит
native-мод с GitHub и пересобирает игру. Обновление — та же команда.

Ключи: `-ContentOnly` / `--content-only` (только контент), `-Local` / `--local`
(собрать native-мод из этой папки, а не с GitHub), `-NoBuild` / `--no-build`.

Проверка, что мод на месте:

* Options → Mods → строка **«The Shooting Star (Demo) 1.5.2: Horizon port»** и
  список его клавиш;
* в `%APPDATA%\horizon\logs\latest.log` есть строка
  `[shooting_star] the original's 48 files are read`.

## Предмет

`shooting_star_demo:stellar_remote` — «Stellar Remote». В креативе ищи по
названию, или командой (ник `mr_pulse`):

```
/give mr_pulse shooting_star_demo:stellar_remote
```

Держи его в руке: касты идут от него.

## Управление (как в оригинале)

| Клавиша | Что делает |
|---|---|
| **правый клик** | каст выбранного заклинания |
| **Shift + правый клик** | следующее заклинание |
| **H** | меню заклинаний (ЛКМ — выбрать, ПКМ — назначить клавишу) |
| **J** | пропустить «плёнку»; если её нет — включить/выключить катсцены |
| **K / I / U / Y / O** | SS-01 / SS-03 / SS-04 / SS-05 / SS-06 |
| **N / M / Z** | мощность / скорость / урон выбранного заклинания (с Shift — вниз) |
| **G** | следующее заклинание |

## Что делает каждое заклинание (размеры по умолчанию, как в оригинале)

* **SS-01 Railgun** — через ≈17,6 с луч радиусом 200 вырезает всё от лимита высоты до пустоты, бедрок тоже. Кастера в креативе эвакуирует.
* **SS-03 Gungnir** — через 16 с игла: кратер 88 блоков в радиусе и 108 вглубь, зона 400, трещины лавы, выжженная земля, вольфрамовый шпиль во всю высоту мира, потом ударная волна с отбросом.
* **SS-04 Seven Stars** — Большой Ковш 1440 блоков: 7 звёзд падают по очереди, кратеры с кристаллами, светящиеся траншеи между ними.
* **SS-05 Tesseract** — квадрат 640×640 из 64 клеток; кубы земли поднимаются в небо четырьмя волнами от центра, остаются ямы с бедроком.
* **SS-06 Gravitia** — мир навсегда становится Imaginary Space (геометрический город в пустоте). Нужен второй клик в течение 10 с.

Подробно, что было исправлено, — в `ИЗМЕНЕНИЯ.md`.
